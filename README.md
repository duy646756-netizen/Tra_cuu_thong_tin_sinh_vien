# Tra cứu thông tin sinh viên

## 1. Giới thiệu

Đây là website tra cứu thông tin sinh viên được xây dựng nhằm hỗ trợ việc tìm kiếm thông tin sinh viên nhanh chóng thông qua mã sinh viên.

## 2. Chức năng

- Nhập mã sinh viên để tra cứu.
- Hiển thị thông tin sinh viên.
- Thông báo khi không tìm thấy sinh viên.
- Kiểm tra trường hợp người dùng chưa nhập mã sinh viên.

## 3. Thông tin hiển thị

Website hiển thị các thông tin:

- Mã sinh viên
- Họ và tên
- Lớp
- Ngành học

## 4. Công nghệ sử dụng

- HTML
- CSS
- JavaScript

## 5. Cấu trúc dự án

```text
Tra_cuu_thong_tin_sinh_vien/

6. Cách sử dụng
Mở file index.html bằng trình duyệt.
Nhập mã sinh viên vào ô tìm kiếm.
Nhấn nút Tra cứu.
Xem thông tin sinh viên được hiển thị.
